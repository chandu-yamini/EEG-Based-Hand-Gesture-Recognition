# EEG Dataset

This directory is intended to document the EEG dataset used in the MSc research project **EEG-Based Hand Gesture Recognition**.

The research investigates the classification of hand movement states using electroencephalography (EEG) signals and machine learning techniques.

## Dataset Overview

The research dataset contains EEG-derived features from four participants, identified as A, B, C and D.

These features support the investigation of EEG-based movement classification using machine learning and hybrid deep learning approaches.

## Research Methods

The project explores:

* EEG signal processing and feature extraction
* Convolutional Neural Networks (CNN)
* Support Vector Machines (SVM)
* Random Forest (RF)
* K-Nearest Neighbours (KNN)
* Model evaluation and performance comparison

## Data Availability

The participant dataset is not currently included in this public repository. Its redistribution permissions and privacy requirements must be verified before publication.
